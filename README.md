# Swaddlely

Shared baby-care logs for parents and caregivers.

Swaddlely helps parents and caregivers keep feeding, diaper changes, sleep and crying records together in a shared household. Log care events, track start and finish times, review history, and leave notes for the next caregiver. It is a web app for care organization, not medical advice or predictions.

Website: https://swaddlely.com/
